## What is Solsmint?

**Solsmint is a no-code platform for creating and managing SPL tokens on
the Solana blockchain.** It helps creators, developers, communities, and
founders perform common token tasks through a web interface instead of
building every transaction flow themselves.

Use Solsmint to create a token, manage its supply, distribute tokens to
multiple wallets, create NFTs, and add or remove liquidity.

-   **Website:** https://www.solsmint.com
-   **Token creation cost:** 0.05 SOL platform price, plus any
    applicable Solana network fees.
-   **Mint more tokens / burn tokens:** 0.03 SOL platform price, plus
    any applicable network fees.
-   **Airdrops:** No Solsmint platform fee; Solana network fees may
    apply.
-   **NFT creation:** No Solsmint platform fee; Solana network fees may
    apply.
-   **Liquidity:** No Solsmint platform fee. Raydium and Solana network
    fees, pool conditions, and transaction costs may apply.

Prices and features can change. Check the live Solsmint website before
making a transaction.

## How to create a Solana token with Solsmint

1.  Open [Solsmint](https://www.solsmint.com/create).
2.  Connect a compatible Solana wallet.
3.  Enter the token details requested by the interface, such as name,
    symbol, supply, decimals, and metadata where available.
4.  Carefully review the details and the wallet transaction.
5.  Approve the transaction in your wallet.
6.  After confirmation, save the token mint address and verify the token
    details using a Solana explorer.

The exact fields and available actions may change as the platform is
updated. Never share your wallet seed phrase or private key with a
website or another person.

## Solana and SPL token basics

Solana is a blockchain network. SPL tokens are tokens that follow
Solana's token standards and programs. Depending on the token program
and configuration, a token may have authorities that control actions
such as minting, freezing accounts, or updating metadata.

Before launching a token, understand:

-   **Mint authority:** May allow additional tokens to be minted while
    it remains active.
-   **Freeze authority:** May allow token accounts to be frozen when
    supported and configured.
-   **Metadata and update authority:** Metadata capabilities and
    permissions depend on the token standard and metadata setup.
-   **Decimals and supply:** These affect how token amounts are
    represented and displayed.
-   **Liquidity pools:** Provide a way for users to trade against pooled
    assets, but do not guarantee buyers, stable prices, or liquidity
    depth.

Authority changes can be difficult or impossible to reverse. Review the
relevant Solana documentation and transaction details before revoking an
authority.

No. Token creation does not guarantee listings, trading activity,
